Evidence philosophy

Claim ≤ Evidence

P01 présente les preuves, mais ne les crée pas. Un README n’est pas un test, un commit n’est pas un run CI, un dépôt public n’est pas automatiquement licencié, et une source privée n’implique pas qu’un projet soit bloqué.

Status legend

Maturité et disponibilité des preuves

Maturité

DOCUMENTED
Scope or decisions are recorded in inspectable documentation.
IMPLEMENTED
Code or an artifact exists; implementation alone is not test evidence.
TESTED
A relevant verification completed successfully.
REPRODUCIBLE
A documented reproduction path has been successfully demonstrated.
PUBLIC
A relevant project surface is publicly accessible; this does not mean production-ready or open source.
EXTERNALLY VALIDATED
Independent external evidence supports the stated claim.

Disponibilité publique

AVAILABLE
Relevant evidence is publicly inspectable.
PARTIAL
Only part of the supporting evidence is publicly inspectable.
PRIVATE SOURCE
The canonical source repository requires authorization.
UNKNOWN
Current evidence availability has not been established.
BLOCKED
A concrete prerequisite prevents evidence publication or inspection.
